Outil de dessin avec style

Si draw.addToMap = false la gestion de la couche sur laquelle dessiner est gérée par le client. C'est le cas dans cet exemple : la sélection d'une couche dans le gestionnaire de couche modifie la couche à modifier.

Il est possible d'ajouter une couche à la carte et de vérifier si la sélection d'une couche se répercute bien sur le widget de dessin.

Si la couche n'est pas modifiable (source n'est pas un ol.source.Vector), une alerte est envoyée.
