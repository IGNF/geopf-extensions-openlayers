Détection des coordonnées désactivée explicitement

L'option coordinateDetection : { active : false, zoom : 18 } désactive la détection : les autres propriétés (ici zoom) sont ignorées. Saisissez un couple de coordonnées dans la recherche simple (ex. 48.502496, 3.384179) : aucune suggestion « coordonnées » n'est proposée, la saisie est envoyée telle quelle à l'autocomplétion de la Géoplateforme.
